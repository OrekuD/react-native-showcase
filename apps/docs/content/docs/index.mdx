## Source first

This is not a traditional package that hides its implementation. You copy the
files you need into your application, then adapt them to your product. The
component pages currently document manual usage while the registry and CLI are
being built.

## Requirements

- A React Native or Expo application
- TypeScript is recommended
- Entry-specific dependencies are listed on each page

## Current library

The first release is intentionally small. It includes three foundational
components and one interaction so the API, documentation, and copy workflow can
settle before the library grows.
