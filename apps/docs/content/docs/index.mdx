## Source first

This is not a traditional package that hides its implementation. You copy the
files you need into your application, then adapt them to your product. The
component pages support both CLI installation and manual source copying as
their registry entries become available.

## Requirements

- A React Native or Expo application
- TypeScript is recommended
- Entry-specific dependencies are listed on each page

## Current library

The library currently includes foundational controls, feedback components,
progress visualizations, and one interaction. Each new entry follows the same
source-first installation and documentation format.
