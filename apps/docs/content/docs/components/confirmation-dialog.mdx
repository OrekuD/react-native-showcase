Confirmation Dialog gives one API for platform alerts and copyable custom
confirmations. Use the familiar imperative form when a decision starts from an
event handler, or use the controlled component when dialog state belongs to
your screen.

## Setup

Mount `ConfirmationDialogHost` once near your app root. It renders custom
dialog portals for both the controlled and imperative APIs.

```tsx
import { View } from 'react-native';
import { ConfirmationDialogHost } from '@/components/ui/confirmation-dialog/ConfirmationDialog';

export function App() {
  return (
    <>
      <View />
      <ConfirmationDialogHost />
    </>
  );
}
```

## Controlled usage

The controlled component works well when the surrounding screen owns the open
state. Custom mode is the default.

```tsx
import { useState } from 'react';
import { Button } from '@/components/ui/button';
import { ConfirmationDialog } from '@/components/ui/confirmation-dialog/ConfirmationDialogApi';

export function DeleteComment() {
  const [open, setOpen] = useState(false);
  const removeComment = () => setOpen(false);

  return (
    <>
      <Button onPress={() => setOpen(true)}>
        <Button.Label>Remove comment</Button.Label>
      </Button>
      <ConfirmationDialog
        cancelLabel="Cancel"
        confirmLabel="Remove"
        description="This comment will be removed everywhere it appears."
        destructive
        dismissible
        onConfirm={removeComment}
        onOpenChange={setOpen}
        open={open}
        title="Remove this comment?"
        variant="compact"
      />
    </>
  );
}
```

## Imperative usage

`alert` follows React Native's `Alert.alert` shape. It renders the compact
custom dialog by default; choose `mode: 'native'` to use the system alert.

```tsx
import { Button } from '@/components/ui/button';
import { ConfirmationDialog } from '@/components/ui/confirmation-dialog/ConfirmationDialogApi';
import { ConfirmationDialogHost } from '@/components/ui/confirmation-dialog/ConfirmationDialog';

export function ImperativeDialogs() {
  const deleteDraft = () => {};

  return (
    <>
      <ConfirmationDialogHost />
      <Button
        onPress={() =>
          ConfirmationDialog.alert(
            'Delete this draft?',
            "You won't be able to recover it after deleting.",
            [
              { text: 'Keep draft', style: 'cancel' },
              {
                text: 'Delete',
                style: 'destructive',
                onPress: deleteDraft,
              },
            ],
          )
        }
      >
        <Button.Label>Delete draft</Button.Label>
      </Button>
      <Button
        onPress={() =>
          ConfirmationDialog.alert('Continue?', undefined, undefined, {
            mode: 'native',
          })
        }
      >
        <Button.Label>Continue</Button.Label>
      </Button>
    </>
  );
}
```

Use `show` when you need custom variants or derived actions.

```tsx
import { Button } from '@/components/ui/button';
import { ConfirmationDialog } from '@/components/ui/confirmation-dialog/ConfirmationDialogApi';
import { ConfirmationDialogHost } from '@/components/ui/confirmation-dialog/ConfirmationDialog';

export function ProminentDialog() {
  return (
    <>
      <ConfirmationDialogHost />
      <Button
        onPress={() =>
          ConfirmationDialog.show({
            cancelLabel: 'Keep request',
            confirmLabel: 'Cancel request',
            description: 'Your payment link will stop working.',
            destructive: true,
            title: 'Cancel this request?',
            variant: 'prominent',
          })
        }
      >
        <Button.Label>Cancel request</Button.Label>
      </Button>
    </>
  );
}
```

## Variants

| Variant | Treatment |
| --- | --- |
| `compact` | Centered copy with equal-width horizontal actions. This is the default. |
| `action-sheet` | Centered copy with full-width, separated action rows. |
| `prominent` | Left-aligned headline with large stacked actions and the cancel action last. |

The custom dialog uses an iOS glass backdrop when the Glass Effect API is
available. Android uses a dimmed RGBA backdrop. The content container remains a
native squircle on both platforms.

```tsx
import { useState } from 'react';
import { Button } from '@/components/ui/button';
import { ConfirmationDialog } from '@/components/ui/confirmation-dialog/ConfirmationDialogApi';

export function ActionSheetDialog() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <Button onPress={() => setOpen(true)}>
        <Button.Label>Mute updates</Button.Label>
      </Button>
      <ConfirmationDialog
        buttons={[
          { text: 'Mute story', style: 'destructive' },
          { text: 'Mute story and posts' },
          { text: 'Cancel', style: 'cancel' },
        ]}
        open={open}
        onOpenChange={setOpen}
        title="Mute updates?"
        variant="action-sheet"
      />
    </>
  );
}
```

## Props

`ConfirmationDialog` accepts the props below. The static `alert` method also
accepts React Native `AlertOptions`, plus `mode`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `buttons` | `AlertButton[]` | — | Explicit actions. Overrides derived confirm and cancel actions. |
| `cancelable` | `boolean` | `true` | Allows backdrop taps and Android back to dismiss a custom dialog. |
| `cancelLabel` | `string` | — | Adds a derived cancel action. |
| `confirmLabel` | `string` | `'OK'` | Label for the derived confirmation action. |
| `description` | `string` | — | Supporting text below the title. |
| `destructive` | `boolean` | `false` | Styles the derived confirmation as destructive. |
| `dismissible` | `boolean` | `false` | Shows a close button for `compact` and `prominent`. |
| `mode` | `'custom' \| 'native'` | `'custom'` | Chooses the custom dialog or platform `Alert`. |
| `onCancel` | `() => void` | — | Runs after a cancel action or permitted dismissal. |
| `onConfirm` | `() => void` | — | Runs after the derived confirmation action. |
| `onOpenChange` | `(open: boolean) => void` | — | Receives open-state changes from the controlled component. |
| `open` | `boolean` | — | Controls the component form. |
| `title` | `string` | — | Dialog heading. |
| `variant` | `'action-sheet' \| 'compact' \| 'prominent'` | `'compact'` | Chooses the custom treatment; ignored in native mode. |
