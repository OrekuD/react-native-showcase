Toast keeps notification state in a provider and renders it through one
safe-area-aware viewport. The default surface is intentionally neutral; build
brand treatments with provider or per-toast theme tokens.

## Setup

Mount one provider and viewport around the part of the app that calls
`useToast`. The safe-area and gesture-handler providers should already wrap
your application.

```tsx
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import { Text } from 'react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { Toast } from '@/components/ui/toast/ToastNamespace';

function AppContent() {
  return <Text>App content</Text>;
}

export function App() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <SafeAreaProvider>
        <Toast.Provider position="bottom" stack="deck">
          <AppContent />
          <Toast.Viewport />
        </Toast.Provider>
      </SafeAreaProvider>
    </GestureHandlerRootView>
  );
}
```

## Show a toast

```tsx
import { Button } from '@/components/ui/button';
import { useToast } from '@/components/ui/toast/Toast';
import { Toast } from '@/components/ui/toast/ToastNamespace';

function SaveButton() {
  const toast = useToast();
  const undoSave = () => {};

  return (
    <Button
      onPress={() =>
        toast.show({
          action: { label: 'Undo', onPress: undoSave },
          message: 'Changes saved',
        })
      }
    >
      <Button.Label>Save</Button.Label>
    </Button>
  );
}

export function SaveToastExample() {
  return (
    <Toast.Provider>
      <SaveButton />
      <Toast.Viewport />
    </Toast.Provider>
  );
}
```

`show` returns the generated id. Use `durationMs: null` for a persistent
notification or `dismissible: true` for an explicit close control.

## Repeat feedback

Pass a stable `id` for repeated events such as copying to the clipboard. If a
matching toast is still visible, its content updates, its timer restarts, and
it pulses instead of adding a duplicate. Once it has left, the same id enters
normally again.

```tsx
import { Button } from '@/components/ui/button';
import { useToast } from '@/components/ui/toast/Toast';
import { Toast } from '@/components/ui/toast/ToastNamespace';

function CopyButton() {
  const toast = useToast();

  return (
    <Button
      onPress={() =>
        toast.show({
          id: 'clipboard-copied',
          message: 'Copied to clipboard',
        })
      }
    >
      <Button.Label>Copy</Button.Label>
    </Button>
  );
}

export function RepeatToastExample() {
  return (
    <Toast.Provider>
      <CopyButton />
      <Toast.Viewport />
    </Toast.Provider>
  );
}
```

## Position, stacking, and swipe

| Provider prop | Options | Default |
| --- | --- | --- |
| `position` | `'top' \| 'bottom'` | `'bottom'` |
| `stack` | `'deck' \| 'vertical'` | `'deck'` |
| `swipeDirections` | `('left' \| 'right' \| 'up' \| 'down')[]` | `['left', 'right']` |

A deck expands into a vertical stack when the leading toast is pressed.
`maxToasts` limits the visible list.

## Theming

Use `ToastThemeProvider` or the `theme` prop on `Toast.Provider` for shared
tokens. Every `toast.show` call can override those tokens locally.

```tsx
import { Button } from '@/components/ui/button';
import { useToast } from '@/components/ui/toast/Toast';
import { Toast } from '@/components/ui/toast/ToastNamespace';

function InviteButton() {
  const toast = useToast();

  return (
    <Button
      onPress={() =>
        toast.show({
          message: 'Your invites are on their way',
          theme: {
            backgroundColor: '#3FAF81',
            borderColor: 'rgba(255, 255, 255, 0.16)',
            borderRadius: 20,
            labelColor: '#FFFFFF',
            layout: { paddingHorizontal: 14, paddingVertical: 9 },
          },
        })
      }
    >
      <Button.Label>Send invites</Button.Label>
    </Button>
  );
}

export function ThemedToastExample() {
  return (
    <Toast.Provider>
      <InviteButton />
      <Toast.Viewport />
    </Toast.Provider>
  );
}
```

## Props

### `Toast.Provider`

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `position` | `'top' \| 'bottom'` | `'bottom'` | Anchors the safe-area-aware viewport. |
| `stack` | `'deck' \| 'vertical'` | `'deck'` | Arranges multiple visible notifications. |
| `maxToasts` | `number` | `3` | Maximum visible notifications. |
| `swipeDirections` | `ToastSwipeDirection[]` | `['left', 'right']` | Allowed dismissal directions. |
| `theme` | `ToastTheme` | — | Provider-local visual tokens. |

### `toast.show`

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `message` | `string` | required | Main notification content. |
| `id` | `string` | generated | Stable identity for updates and repeat feedback. |
| `icon` | `ReactNode` | — | Leading visual. |
| `action` | `ToastAction` | — | Trailing labeled action. |
| `dismissible` | `boolean` | `false` | Shows an accessible close control. |
| `durationMs` | `number \| null` | `5000` | Lifetime; `null` keeps the toast visible. |
| `theme` | `ToastThemeOverride` | — | Visual tokens for this notification only. |
