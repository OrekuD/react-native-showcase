Components are the quiet building blocks of the library. They stay focused,
depend on as little as possible, and are designed to be copied directly into an
application.

## Design rules

- Prefer React Native primitives for foundational controls.
- Keep dependencies optional and visible.
- Preserve accessibility behavior from the underlying native control.
- Expose only the variants that have a clear purpose.
