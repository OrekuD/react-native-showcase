Menu gives you a composed custom popover for richly detailed actions, or Expo
UI's native menu when platform behavior is the better fit. Both start from the
same `Menu` and `Menu.Trigger` API.

optional item feedback, and Fast Squircle for the popover shape. Native mode
also requires Expo UI.

## Usage

`Menu.Trigger` accepts one pressable child. The custom menu is the default and
items close it after selection.

```tsx
import { Camera, Images } from 'lucide-react-native';
import { Button } from '@/components/ui/button';
import { Menu } from '@/components/ui/menu';

<Menu>
  <Menu.Trigger>
    <Button variant="outline">
      <Button.Label>Add media</Button.Label>
    </Button>
  </Menu.Trigger>

  <Menu.Content align="start">
    <Menu.Item
      description="Take a new photo or video."
      icon={<Camera color="#151513" size={20} />}
      onSelect={openCamera}
    >
      Camera
    </Menu.Item>
    <Menu.Item
      icon={<Images color="#151513" size={20} />}
      onSelect={openLibrary}
    >
      Photos
    </Menu.Item>
  </Menu.Content>
</Menu>
```

## Custom menu

Compose `Menu.Section`, `Menu.Item`, and `Menu.Separator` inside
`Menu.Content`. Items may include an icon, description, destructive treatment,
and optional light haptic feedback. They scale briefly on press without adding
a pressed background.

```tsx
<Menu.Content align="end" size="compact">
  <Menu.Item icon={<Camera color="#151513" size={20} />}>Camera</Menu.Item>
  <Menu.Item icon={<Images color="#151513" size={20} />}>Photos</Menu.Item>
  <Menu.Item destructive haptics onSelect={removeMedia}>
    Delete
  </Menu.Item>
</Menu.Content>
```

| `size` | Treatment |
| --- | --- |
| `default` | Spacious rows for leading icons and optional descriptions. Default. |
| `compact` | Smaller rows, icons, and spacing for quick actions. |

## Native mode

Pass `mode="native"` and Expo UI-compatible actions to render the platform
menu. Native mode uses the same trigger composition, but does not render
`Menu.Content`.

```tsx
<Menu
  actions={[
    { id: 'rename', image: 'pencil', title: 'Rename' },
    { id: 'delete', image: 'trash', title: 'Delete', attributes: { destructive: true } },
  ]}
  mode="native"
  onSelect={(id) => console.log(id)}
  title="File"
>
  <Menu.Trigger>
    <Button variant="outline">
      <Button.Label>File actions</Button.Label>
    </Button>
  </Menu.Trigger>
</Menu>
```

## Theming

`MenuThemeProvider` applies shared tokens to custom menus in its subtree. Pass
`theme` directly to one custom Menu for a local override. Native mode keeps the
platform menu appearance.

```tsx
import { Menu, MenuThemeProvider } from '@/components/ui/menu';

<MenuThemeProvider
  theme={{
    backgroundColor: '#EEF4FF',
    iconBackgroundColor: '#DDEAFF',
    labelColor: '#172B4D',
    separatorColor: '#C7D8F5',
  }}
>
  <FileMenu />
</MenuThemeProvider>
```

## Props

### `Menu`

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `mode` | `'custom' \| 'native'` | `'custom'` | Chooses the custom popover or Expo UI native menu. |
| `defaultOpen` | `boolean` | `false` | Initial visibility for an uncontrolled custom menu. |
| `open` | `boolean` | — | Controls custom-menu visibility. |
| `onOpenChange` | `(open: boolean) => void` | — | Receives custom-menu visibility changes. |
| `shouldOpenOnLongPress` | `boolean` | `false` | Opens from a long press rather than a tap. |
| `testID` | `string` | — | Applies a native test identifier to the trigger. |
| `theme` | `MenuThemeOverride` | — | Overrides custom menu tokens locally. |
| `actions` | `NativeMenuAction[]` | — | Expo UI actions; required only with `mode="native"`. |
| `onSelect` | `(id: string) => void` | — | Receives the selected action id in native mode. |
| `title` | `string` | — | iOS title for the native menu. |

### `Menu.Content` and `Menu.Item`

| Prop | Component | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `align` | `Content` | `'start' \| 'end'` | `'end'` | Aligns the popover with the trigger edge. |
| `sideOffset` | `Content` | `number` | `8` | Gap between the trigger and popover. |
| `size` | `Content` | `'default' \| 'compact'` | `'default'` | Sets the density for every item inside it. |
| `description` | `Item` | `ReactNode` | — | Supplemental copy below the label. |
| `destructive` | `Item` | `boolean` | `false` | Applies destructive text color. |
| `disabled` | `Item` | `boolean` | `false` | Prevents selection. |
| `haptics` | `Item` | `boolean` | `false` | Plays light impact feedback after selection. |
| `icon` | `Item` | `ReactNode` | — | Leading icon inside a round container. |
| `onSelect` | `Item` | `() => void` | — | Runs after the custom menu closes. |

`Menu.Section` accepts `title?: string`; `Menu.Separator` does not accept
props.
