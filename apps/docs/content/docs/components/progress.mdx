Progress turns a numeric value into a squircle-backed horizontal indicator. It
animates value changes by default and clamps values safely against `max`.

## Usage

```tsx
import { Progress } from '@/components/ui/progress';

<Progress value={72} />
```

Use `max` when the source value is not already a percentage. Dimensions and
colors can be set directly without replacing the base theme.

```tsx
<Progress
  color="#BB3E61"
  height={16}
  max={250}
  trackColor="#F4D8DF"
  value={180}
  width="72%"
/>
```

## Animation

Value changes use a reduced-motion-aware timing transition. Disable it for an
instant update or tune its duration.

```tsx
<Progress animated={false} value={completed} />
<Progress durationMs={480} value={completed} />
```

## Theming

```tsx
import { Progress, ProgressThemeProvider } from '@/components/ui/progress';

<ProgressThemeProvider
  theme={{ indicatorColor: '#2E8F6A', trackColor: '#DDE9E1' }}
>
  <Progress value={74} />
</ProgressThemeProvider>
```

Use `theme` on one Progress for a local override. Direct `color` and
`trackColor` props take precedence over theme values.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number` | `0` | Current completed value. |
| `max` | `number` | `100` | Value considered complete. |
| `animated` | `boolean` | `true` | Animates value changes. |
| `durationMs` | `number` | `280` | Timing duration in milliseconds. |
| `height` | `number` | `10` | Track height. |
| `width` | `DimensionValue` | `'100%'` | Track width. |
| `color` | `string` | theme | Indicator color. |
| `trackColor` | `string` | theme | Remaining-track color. |
| `theme` | `ProgressThemeOverride` | — | Local visual tokens. |

Progress also accepts React Native `ViewProps`, except `children`, and composes
the supplied `style` with its dimensions and colors.
