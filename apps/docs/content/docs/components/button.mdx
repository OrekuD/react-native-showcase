The Button is a source-first compound component. Compose `Button.Label` and
`Button.Icon` to keep text, icons, loading indicators, and accessibility in one
consistent interaction model.

## Usage

```tsx
import { Button } from '@/components/ui/button';

export function Actions() {
  const save = () => {};
  const preview = () => {};
  const openDocs = () => {};

  return (
    <>
      <Button onPress={save}>
        <Button.Label>Save changes</Button.Label>
      </Button>

      <Button haptics onPress={preview} variant="secondary">
        <Button.Label>Preview</Button.Label>
      </Button>

      <Button onPress={openDocs} variant="ghost">
        <Button.Label>Learn more</Button.Label>
      </Button>
    </>
  );
}
```

Add an icon with a render function when the icon needs the active foreground
color and size:

```tsx
import { Download } from 'lucide-react-native';
import { Button } from '@/components/ui/button';

export function DownloadButton() {
  return (
    <Button onPress={() => {}}>
      <Button.Icon>
        {({ color, size }) => <Download color={color} size={size} />}
      </Button.Icon>
      <Button.Label>Download file</Button.Label>
    </Button>
  );
}
```

For an icon-only button, use `size="icon"` and provide an accessible name:

```tsx
import { Plus } from 'lucide-react-native';
import { Button } from '@/components/ui/button';

export function AddButton() {
  return (
    <Button accessibilityLabel="Add item" size="icon">
      <Button.Icon>
        {({ color, size }) => <Plus color={color} size={size} />}
      </Button.Icon>
    </Button>
  );
}
```

## Sizes

`md` is the default. Use `sm` for compact actions, `lg` for a more prominent
touch target, and `icon` for a square icon-only control. Each size keeps the
height, horizontal padding, icon slot, and label font size in sync.

```tsx
import { Plus } from 'lucide-react-native';
import { Button } from '@/components/ui/button';

export function ButtonSizes() {
  return (
    <>
      <Button size="sm">
        <Button.Label>Small</Button.Label>
      </Button>

      <Button size="md">
        <Button.Label>Medium</Button.Label>
      </Button>

      <Button size="lg">
        <Button.Label>Large</Button.Label>
      </Button>

      <Button accessibilityLabel="Add item" size="icon">
        <Button.Icon>
          {({ color, size }) => <Plus color={color} size={size} />}
        </Button.Icon>
      </Button>
    </>
  );
}
```

## Variants

| Variant | Purpose |
| --- | --- |
| `primary` | The main action in a group. |
| `secondary` | A quieter filled action on the current surface. |
| `outline` | A bordered action with a transparent background. |
| `ghost` | A low-emphasis action on an existing surface. |
| `destructive` | A destructive action with a light red boundary and red content. |

## States

Use `disabled` when an action is unavailable and `loading` when the action is
being processed. Loading also disables the press target, marks it busy for
assistive technology, and swaps each icon slot for an `ActivityIndicator`.

```tsx
import { useState } from 'react';
import { Button } from '@/components/ui/button';

export function ButtonStates() {
  const [isSaving, setIsSaving] = useState(false);

  const save = () => {
    setIsSaving(true);
    setTimeout(() => setIsSaving(false), 900);
  };

  return (
    <>
      <Button disabled>
        <Button.Label>Unavailable</Button.Label>
      </Button>

      <Button loading={isSaving} onPress={save}>
        <Button.Label>{isSaving ? 'Saving' : 'Save changes'}</Button.Label>
      </Button>
    </>
  );
}
```

Set `haptics` to enable a light impact after a successful press. It is disabled
by default and can be toggled per button.

## Props

`Button` accepts all React Native `PressableProps` and adds the props below.
The compound API still lets you compose content with `Button.Label` and
`Button.Icon`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `accessibilityLabel` | `string` | — | Inherited from `Pressable`; required for icon-only buttons. |
| `haptics` | `boolean` | `false` | Adds light impact feedback after a successful press. |
| `loading` | `boolean` | `false` | Disables interaction and swaps icon slots for an activity indicator. |
| `size` | `'sm' \| 'md' \| 'lg' \| 'icon'` | `'md'` | Controls button height, spacing, and icon-only layout. |
| `theme` | `ButtonThemeOverride` | — | Overrides appearance, typography, sizing, and corner smoothing for one button. |
| `variant` | `ButtonVariant` | `'primary'` | Selects the visual treatment: `primary`, `secondary`, `outline`, `ghost`, or `destructive`. |

All other `PressableProps` pass through to the underlying control, including
`children`, `disabled`, `style`, event handlers, accessibility props, and
`testID`. `children` can be compound content or a Pressable render function;
`style` supports both static styles and Pressable's `(state) => style` form.

An icon-only button must provide `accessibilityLabel`. The `Button.Icon` render
function receives the resolved `color` and `size` tokens for the active variant
and size.

## Theming

Use `ButtonThemeProvider` for shared defaults, or pass `theme` to one Button
when a local treatment is needed. Both approaches preserve the compound API.

```tsx
import {
  Button,
  ButtonThemeProvider,
} from '@/components/ui/button';

export function ThemedButton() {
  return (
    <ButtonThemeProvider
      theme={{
        cornerSmoothing: 0.9,
        label: { fontSize: 17 },
        sizes: {
          lg: {
            height: 64,
            labelFontSize: 19,
            paddingHorizontal: 30,
          },
        },
        variants: {
          primary: {
            backgroundColor: '#28594A',
            foregroundColor: '#F4FBF7',
          },
        },
      }}
    >
      <Button>
        <Button.Label>Provider theme</Button.Label>
      </Button>
    </ButtonThemeProvider>
  );
}
```

The per-button `theme` override accepts appearance, label, size, and corner
smoothing tokens without changing the provider defaults.

## Motion

Press feedback eases the button to `0.97` scale and returns it to rest on release.
Loading icons mount from the center with a short zoom transition and unmount
with a faster zoom-out transition. The fixed icon slot prevents either state
from shifting the label. Press and icon transitions respect the system
reduce-motion preference.
