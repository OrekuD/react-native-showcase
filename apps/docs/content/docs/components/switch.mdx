Switch is a source-first setting row. Use its custom control for the Showcase
treatments or opt into React Native's platform switch while retaining the same
label, haptics, and on/off color model.

## Usage

```tsx
import { useState } from 'react';
import { Switch } from '@/components/ui/switch';

export function MotionSetting() {
  const [reduceMotion, setReduceMotion] = useState(false);

  return (
    <Switch
      description="Prefer calmer transitions throughout the app."
      haptics
      label="Reduce motion"
      onValueChange={setReduceMotion}
      value={reduceMotion}
    />
  );
}
```

The custom solid treatment is the default. It is controlled by `value` and
`onValueChange`, just like React Native's Switch.

## Modes and variants

Use `mode="native"` when the platform switch is a better fit. Native mode
still uses the shared on/off theme colors and the optional `haptics` feedback.

| Mode | Purpose |
| --- | --- |
| `custom` | Showcase's squircle-based, animated control. This is the default. |
| `native` | React Native's platform Switch. |

Custom mode has three treatments:

| Variant | Purpose |
| --- | --- |
| `solid` | Standard filled track with a comfortable thumb inset. Default. |
| `solid-tight` | Filled track with a tighter thumb inset. |
| `outline` | Transparent track with a visible border. |

```tsx
import { useState } from 'react';
import { Switch } from '@/components/ui/switch';

export function SwitchModes() {
  const [solid, setSolid] = useState(false);
  const [outlined, setOutlined] = useState(false);
  const [systemSetting, setSystemSetting] = useState(false);

  return (
    <>
      <Switch label="Solid" value={solid} onValueChange={setSolid} />
      <Switch
        label="Outline"
        value={outlined}
        onValueChange={setOutlined}
        variant="outline"
      />
      <Switch
        label="System setting"
        mode="native"
        value={systemSetting}
        onValueChange={setSystemSetting}
      />
    </>
  );
}
```

## Thumb icons

Pass optional `on` and `off` React nodes with `thumbIcons`. The icon frame
stays centered in the moving thumb: the next icon scales in and the previous
one fades out faster from the same position.

```tsx
import { Check, X } from 'lucide-react-native';
import { useState } from 'react';
import { Switch } from '@/components/ui/switch';

export function IconSwitch() {
  const [notificationsEnabled, setNotificationsEnabled] = useState(false);

  return (
    <Switch
      label="Notifications"
      value={notificationsEnabled}
      onValueChange={setNotificationsEnabled}
      variant="solid-tight"
      thumbIcons={{
        off: <X color="#A1A1AA" size={15} strokeWidth={2.5} />,
        on: <Check color="#5962EE" size={15} strokeWidth={2.8} />,
      }}
    />
  );
}
```

Icons apply only to custom mode. Each state is optional, so either side can be
intentionally icon-free.

## Theming

`SwitchThemeProvider` shares semantic `on` and `off` colors with every Switch
in its subtree. The same colors drive custom tracks and thumbs, as well as the
native `trackColor` and `thumbColor` values. Border color is used by custom
mode only.

```tsx
import { useState } from 'react';
import {
  Switch,
  SwitchThemeProvider,
} from '@/components/ui/switch';

export function ThemedSwitches() {
  const [custom, setCustom] = useState(false);
  const [native, setNative] = useState(false);

  return (
    <SwitchThemeProvider
      theme={{
        off: {
          borderColor: '#AAB9B1',
          thumbColor: '#FFFFFF',
          trackColor: '#DDE9E1',
        },
        on: {
          borderColor: '#28594A',
          thumbColor: '#FFFFFF',
          trackColor: '#28594A',
        },
      }}
    >
      <Switch label="Custom" value={custom} onValueChange={setCustom} />
      <Switch
        label="Native"
        mode="native"
        value={native}
        onValueChange={setNative}
      />
    </SwitchThemeProvider>
  );
}
```

Override the same semantic states on one Switch without repeating its active
variant:

```tsx
import { useState } from 'react';
import { Switch } from '@/components/ui/switch';

export function LocallyThemedSwitch() {
  const [isPrivate, setIsPrivate] = useState(false);

  return (
    <Switch
      label="Private account"
      value={isPrivate}
      onValueChange={setIsPrivate}
      variant="outline"
      theme={{
        on: { borderColor: '#8B5CF6', thumbColor: '#8B5CF6' },
        off: { borderColor: '#D1D5DB', thumbColor: '#A1A1AA' },
      }}
    />
  );
}
```

## Haptics and motion

Set `haptics` to enable selection feedback when a user changes the value. It is
off by default. Custom switches animate track, thumb, and border colors from a
single 140ms eased progress value, so rapid toggles reverse smoothly. The icon
swap respects the system reduce-motion preference.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `description` | `string` | — | Supporting text below the visible label. |
| `disabled` | `boolean` | `false` | Prevents value changes and dims the row. |
| `haptics` | `boolean` | `false` | Adds selection feedback after a value change. |
| `label` | `string` | — | Visible label and accessible name. |
| `mode` | `'custom' \| 'native'` | `'custom'` | Selects the custom or platform control. |
| `onValueChange` | `(value: boolean) => void` | — | Receives the next controlled value. |
| `testID` | `string` | — | Identifier for automated tests. |
| `theme` | `SwitchThemeOverride` | — | Local on/off color and corner-smoothing overrides. |
| `thumbIcons` | `{ on?: ReactNode; off?: ReactNode }` | — | Custom-mode icons rendered in the thumb. |
| `variant` | `'solid' \| 'solid-tight' \| 'outline'` | `'solid'` | Selects the custom treatment; ignored by native mode. |
| `value` | `boolean` | — | Controlled checked value. |

## Accessibility

Custom mode exposes the `switch` role, the current checked state, disabled
state, and the visible label as its accessible name. Native mode delegates the
interaction semantics to React Native's platform Switch.
